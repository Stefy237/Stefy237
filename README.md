## What I work on

I like the layer where software meets the machine it actually runs on: build pipelines that fail loudly instead of silently, servers that come back up the way you left them, and scripts that remove the task nobody wanted to do twice.

At Alstom I rebuilt a GitLab CI pipeline around modular, incremental builds and cut delivery time by roughly half. I provisioned Debian servers with Ansible, automated integration test suites with Robot Framework, and ran all of it on a virtualized Linux/FreeBSD platform under VMware ESXi.

Before that I built mobile and full-stack applications — which is part of why I care about what happens *after* the code is written.
